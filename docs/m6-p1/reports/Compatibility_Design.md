## Optional presentation extension

The schema8 M6 family remains unchanged mechanically. New candidates may include `m6.presentation = {version:1, drivers:{key:{version:1, ancestryId:"A01".."A13",sex:"male"|"female"}},staff:{id:{version:1,ancestryId,sex}}}`. The extension is strictly validated, generated from existing immutable identities in a separate hash domain, and has no simulation/economic role. Driver keys are immutable rival member IDs; disposable Den keys bind event+entrant. Persistent Den rivals reuse their national driver member identity. Existing authored staff ancestry/sex are preserved; absent staff ancestry follows the existing national pool with independent deterministic sampling. Staff keys transfer from offer to owned identity without changing context-derived values. Dead references are removed at committed lifecycle boundaries, not on reads.

Owned/market drivers retain the existing `m6.driverVisuals` authority. Acquisition transfers its exact value before removing the offer. Cleanup checks both identity and visual indexes independently. Existing saves without the extension load unchanged; presentation can be derived without a write. New careers and subsequent accepted decisions persist the extension. New code accepts old schema8 saves; older M6 executables reject the added field rather than discard it. No legacy automatic migration. All existing envelope/export/backup paths serialize the complete state and must preserve this field.
