# Blood and Thunder — E5-D M1 Windows/browser acceptance

M1 only. Owner acceptance is still required. No M2–M7 implementation, merge, push or release is authorized by this delivery.

## Open the correct artifact

Use **Blood-and-Thunder-E5-D-M1-Playable.html**, not the preserved E5-C/C.1 files. Keep an external complete backup of valuable careers before testing. Keep the original E5-C.1 HTML and browser profile.

1. Download the individual HTML file. In Windows Explorer, open it in current Chrome or Edge. Confirm the address starts with `file:///`.
2. Disconnect the network. There must be no adjacent script, image, font or server requirement. The first screen should show loading followed by the title and upper-left wheel.
3. The managed Linux test browser blocks all direct-file launches with `ERR_BLOCKED_BY_ADMINISTRATOR`; its HTTP tests do not establish Windows acceptance. Please report browser/version and any direct-file storage or Worker errors.
4. Optional PowerShell integrity check: `Get-FileHash .\Blood-and-Thunder-E5-D-M1-Playable.html -Algorithm SHA256`. Compare against the implementation/test report.

## Two independent careers — transitional M1 creation

1. On an empty browser profile, Continue is disabled and explains why. Choose **New Game**. Enter owner/stable names, then confirm the in-game dialog.
2. M1 creates an **empty, separate, durable career**, not an automatic starting grant. It opens the existing **Save & Recovery** page. Choose an approved package and **Review starting package**, then confirm. The package is granted once through the existing authority.
3. Use **Enable the next stable service** twice to explicitly enable the existing economy, then payroll/contracts. These are the existing compatibility operations; no cycle or free recovery is charged by browsing.
4. Visit Roster & Racing Unit. Inspect the real owned assets and commit a legal unit if needed. Visit Championships and explicitly enable championship progression. Choose a championship and owned assignment, inspect the schedule, then confirm registration.
5. Use the wheel → Return to Title. Create Stable B with a different name/package. Never replace or rename A's IDs to make B.
6. Use Load Game to alternate A/B. Check names, Gold, assets, condition, assignments, contracts, championships and records. Merely opening A must not make it newer than B's last committed save.
7. Continue uses actual committed save time. Unknown older timestamps, identical latest timestamps, corrupt slots or unavailable authority require explicit Load Game selection. They do not cause silent substitution.

## Options and the real race

1. Prepare/start a genuine championship race manually. Confirm the accepted top-down viewer, tactical map, standings, radio, pause, step, speed and Strategy Signs remain available.
2. Queue one Sign before starting. Open the wheel while paused: the worker pause must be acknowledged; closing Options must leave it paused. The queued Sign and remaining opportunities must be unchanged.
3. Start/resume at a chosen playback speed. Open Options during racing. The displayed race must stop after the pending authoritative operation completes. Close Options: prior running playback should resume at the same speed.
4. Repeat while already paused. It must stay paused. Escape and browser Back should close Options safely and return focus to the wheel.
5. From Options, try Return to Title or switching while a championship is unfinished. Cancel the styled confirmation; the same screen/progress must remain. Confirm only when you intend to leave the race **saved and paused**, not withdrawn or rerolled. Reopen that slot and resume its saved race.
6. Finish the actual race. Use the existing Pause & return to Championship control, then publish the official result. An unfinished/blocked race must not manufacture a result.
7. Open Options during the Run choice, final settlement and Legacy choice. Leave/reopen between choices and verify each pending choice is retained. Finish the schedule and settle once; repeating navigation must not credit rewards twice.
8. After a Legacy selection, open the other career. It must not inherit that Legacy record or any money/assets from the completed career.
9. Repeat normal stable navigation at least 20 cycles. There must remain at most one Continue Championship control and one wheel, with no button accumulation.

## Save/Load, backups and recovery

- Ordinary play saves automatically; there is no fake manual Save control. Read the real save/recovery status. A pending operation must block leaving until its authoritative result is known.
- Wheel → Save & Load exposes slots and optional backups. **Complete championship backup** includes required sessions/journals. **Career-only JSON** is the distinct historical format and is insufficient for an active external race session.
- A browser download request does not verify a file exists on disk. Check the downloaded file yourself.
- To transfer a pre-M1 complete backup into a new browser/file context: title → Load Game → **Restore a complete backup as a separate career**. Confirm. The original profile/career IDs and Legacy are retained, never merged or renamed. Load the resulting slot. Importing a duplicate identity into another slot is refused.
- To restore the current career, use its optional import controls and explicit confirmation. A malformed or unrelated complete backup must leave its authority intact. Use only copies for negative testing.
- If creation/import was interrupted after a durable stage, its reserved slot stays listed. **Recover interrupted creation or import** retries only retained, validated evidence after confirmation; it does not invent a new career, starting grant or missing session.
- A missing/corrupt slot must remain listed as needing attention. Other valid slots can be explicitly loaded. No stale legacy fallback, automatic replacement, erased history or fabricated save time is permitted.
- If browser storage is denied, M1 refuses automatic creation safely. Enable storage permissions/use a normal profile; it does not claim an in-memory change was saved.
- Slot deletion is deliberately not offered in M1. Do not clear browser storage to repair a valuable career without first preserving complete backups.
